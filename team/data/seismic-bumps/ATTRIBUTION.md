# seismic-bumps

Источник: Sikora M., Wróbel Ł. *Seismic Bumps* [Dataset]. UCI Machine Learning Repository, 2010.
https://doi.org/10.24432/C5W902 — лицензия CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).

Файл `seismic-bumps.arff` скопирован без изменений. В решении используется для калибровки
частоты и энергии сейсмических толчков за смену (team/mine/config.py, SEISMIC): 2 584 смены
подземного угольного рудника, 170 смен с опасным толчком, классы оценки опасности a/b.
